# Development History

The project began as a persistent word tracker because Letter Boxed itself does not retain a rich player history. It evolved through layout integration, exhaustive Twofer analysis, spoiler-conscious hints, responsive resizing, official-solution annotation, export/import, migration/enrichment, custom vocabulary, and experimental animation controls.

## Source fidelity

- `v1.6.0+`: exact retained generated artifacts.
- `v1.0.0-v1.5.0`: reconstructed from contemporaneous chat requirements because the original downloadable artifacts were not retained. The reconstruction status is explicit in both source comments and commit messages.
