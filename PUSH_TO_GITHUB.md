# Push this prepared repository to GitHub

This ZIP contains a real `.git` directory with sequential version commits and tags.

Create an **empty** GitHub repository named `letter-boxed-cubed` (do not initialize README/.gitignore/license), then run:

```bash
git remote add origin https://github.com/Msyjsm/letter-boxed-cubed.git
git push -u origin main --tags
```

GitHub Desktop can also publish this local repository while preserving its existing history.

Suggested topics: `letter-boxed`, `nyt-games`, `tampermonkey`, `userscript`, `word-game`, `javascript`.

## Repository organization

Personal GitHub accounts do not have nested folders of repositories. Repositories are top-level; normal folders exist *inside* each repo. Organize repos with topics, naming conventions, search/language filters, pinned repos, or a GitHub Organization if you eventually want a stronger hierarchy.
